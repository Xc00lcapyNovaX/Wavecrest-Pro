API Documentation

Complete reference for the Wavecrest Pro REST API. Integrate trend intelligence into your own tools and workflows.

Base URL

All endpoints are relative to:

http://localhost:3000  ← development
https://wavecrest.pro  ← production

Authentication

Session-based authentication using HTTP cookies. Sign up or log in first, then include credentials: 'include' in fetch requests or -b cookies.txt with cURL.

Rate Limits

Daily request limits vary by plan. Check headers X-RateLimit-Limit and X-RateLimit-Remaining.

PlanDaily LimitPrice
Free10$0
Plus50$9.99/mo
Pro500$24.99/mo
MaxUnlimited$99.99/mo
TeamsUnlimited$49.99/person/mo
EnterpriseUnlimitedCustom

Error Handling

All errors return JSON with an error field:

{"error": "Description of what went wrong"}
CodeMeaning
400Bad request — missing or invalid parameters
401Not authenticated — sign in first
403Plan upgrade required
404Resource not found
429Rate limit exceeded
500Internal server error

Auth API

POST /api/auth/signup

Register a new user account with email and password. A session cookie is automatically set on success.

curl -s -b cookies.txt -X POST http://localhost:3000/api/auth/signup \
  -H 'Content-Type: application/json' \
  -d '{}'
const res = await fetch('/api/auth/signup', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  credentials: 'include',
  body: JSON.stringify({})
});
const data = await res.json();
import requests
res = requests.post('http://localhost:3000/api/auth/signup', json={})
data = res.json()
